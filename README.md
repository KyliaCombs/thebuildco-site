# thebuildco-site

The Build Co's website, built with [Astro](https://astro.build). For now it's a
single "Coming soon" placeholder page.

## Running it

You need [Node.js](https://nodejs.org) installed (version 22 or newer).

```bash
npm install      # first time only: downloads Astro into node_modules/
npm run dev      # starts a local preview at http://localhost:4321
```

Other commands:

- `npm run build` builds the finished site into `dist/`
- `npm run preview` serves that built site locally to check it

## Folders

- `src/pages/` holds the site's pages; `index.astro` is the home page
- `design/reference/` holds design reference material (empty for now)
